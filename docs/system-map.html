algo-sys-v1 system map

Five Go processes that talk only through Redis. Angel One ticks become 1-second and timeframe candles, then indicators, analysis and signals; orders go back to Angel One from one executor. The browser sees all of it through the API gateway.

money: int64 paise time: EventTS → CanonicalTS() bus: Redis pub/sub + streams durable: SQLite real orders: NIFTY50_FNO only

The five services

mdengine

Angel One WebSocket ingest, 1-second OHLC, timeframe candles. Buffers final candles through a Redis outage and restores missed ones from SQLite.

metrics :9090 (METRICS_ADDR)

indengine

Indicators per token and timeframe. One goroutine owns the engine; each indicator skips candles it has already applied.

http :9095 · /reload

analyst

Market state, support/resistance and breakouts from 1-minute candles.

pub:analyst:*

stratengine

Strategies, signals, order execution, P&L from fills, EOD exit at 15:20.

metrics :9096

api_gateway

REST and WebSocket to the dashboard, with per-channel sequence numbers, epochs and replay.

GATEWAY_ADDR :9090

One real order, start to finish

The order is saved before Angel One sees it, P&L is booked only from fills, and an exit is never blocked. A failed exit is resent after checking the broker's net position.

%%{init: {'theme':'neutral'}}%%
sequenceDiagram
    autonumber
    participant S as Strategy
    participant L as signalLoop
    participant Q as Order queue
    participant E as orderexec
    participant R as Redis snapshot
    participant B as Angel One
    participant P as P&L / portfolio

    S->>L: BUY signal
    L->>L: kill switch · market open · EOD cutoff · profit cap
    L->>Q: dispatch before journal, publish, notify
    L-->>L: journal · pub:signal · notify (async)
    Q->>E: ExecuteSignal
    E->>E: position gate · rate limit · breaker
    E->>R: save intent (Pending, ordertag)
    alt save failed
        E-->>E: BUY not sent, operator alert
    else saved
        E->>B: PlaceOrder with ordertag
        B-->>E: order id, or ambiguous
        E->>B: settle by tag in order book (one safe resend)
        E->>B: GTT target + stop loss
        E->>P: fill report (average price)
        E->>R: snapshot
    end

    S->>L: EXIT signal
    L->>Q: dispatch
    Q->>E: ExecuteSignal (never blocked)
    E->>R: mark exit by tag (sent even if save fails)
    E->>B: SELL
    alt filled
        E->>B: cancel paired GTTs
        E->>P: fill report (SELL)
    else failed, rejected or partial
        E->>B: read net position
        E->>B: resend after 5 s, 15 s, 30 s, 60 s, or close record if flat
    end

    Note over E,B: On restart, ResumeSettlement finds Pending and tagged exits in the order book by ordertag.
    Note over L,E: 15:20 IST: strategy exits, then a sweep of executor-held positions. 15:25: alert if anything is still open.

Channels the browser receives

The gateway forwards these Redis channels over WebSocket, each with its own sequence number and replay buffer.

ChannelPublished byCarries
pub:tick:*mdengineLive LTP per token
pub:candle:{tf}s:*mdengineForming and final candles (the gateway subscribes explicitly)
pub:ind:*indengineIndicator values per name, timeframe and token
pub:analyst:*analystMarket state, levels, breakouts, summary
pub:signal · pub:orders · pub:pnl · pub:strikestratengineSignals, live orders, P&L summary, selected strikes

Safety guards on the money path

  • real orderSent only when the strategy is NIFTY50_FNO, LiveOrders is on and the Angel session is up. Everything else is paper with a PAPER_* ID.
  • intentA real BUY is saved to Redis before sending; if the save fails, the BUY is not sent.
  • exitsNever refused by the rate limiter, circuit breaker or profit cap. Failed exits are resent automatically.
  • exchangeEach filled entry gets a GTT target (+1.5%) and a GTT stop loss at Angel One.
  • end of dayEntries blocked and positions closed at STRAT_EOD_EXIT_TIME (default 15:20 IST).
  • toolsteststrategyorder, testposition and cancelorder need --i-understand-real-money and a typed REAL.
  • deployProduction deploy runs only after CI (build, vet, test -race, frontend test and build) passes.
